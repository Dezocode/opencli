The script must include these 6 test patterns with full working code:

### Pattern 1: Quick Permission Buffer Test (Visual Mode)
- Uses `create_permission_buffer_test()` helper
- Opens LEFT and RIGHT terminal windows
- Tests `/help` command permission buffer
- Shows auto-detection of failing functions

### Pattern 2: Custom Navigation Test
- Uses `TUITestFramework()` with custom test steps
- Tests arrow key navigation (UP/DOWN)
- Includes BEFORE/AFTER state validation
- Verifies selection changes

### Pattern 3: Headless Test (CI/CD Mode)
- No visual windows
- Returns exit codes (0 for pass, 1 for fail)
- Suitable for CI/CD pipelines
- Shows failing functions in output

### Pattern 4: Test Multiple Commands
- Loop through list of slash commands
- Test each command individually
- Collect pass/fail results
- Generate summary report

### Pattern 5: Custom Validation
- User-defined verify functions
- Custom test logic
- State-based checks

### Pattern 6: State Collection & Analysis
